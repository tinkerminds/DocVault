## Day 1 — Foundation

### Step 1 — Create Resource Group

```bash
az group create \
  --name $RESOURCE_GROUP \
  --location $LOCATION
```

All DocVault resources live in a single resource group for easy management and teardown.

---

### Step 2 — Create Storage Account

```bash
az storage account create \
  --name $STORAGE_ACCOUNT \
  --resource-group $RESOURCE_GROUP \
  --location $LOCATION \
  --sku Standard_LRS \
  --kind StorageV2 \
  --access-tier Hot
```

| Setting        | Reason                                           |
| -------------- | ------------------------------------------------ |
| `Standard_LRS` | Locally redundant — sufficient for dev           |
| `StorageV2`    | General-purpose v2 — supports Blob, Queue, Table |
| `Hot`          | Frequently accessed documents                    |

---

### Step 3 — Create Blob Containers

```bash
# Uploads container (user documents)
az storage container create \
  --name $BLOB_CONTAINER \
  --account-name $STORAGE_ACCOUNT \
  --public-access off

# Thumbnails container (generated by Azure Function)
az storage container create \
  --name $THUMBNAILS_CONTAINER \
  --account-name $STORAGE_ACCOUNT \
  --public-access off
```

- Public access is **off** — all access goes through the API with SAS tokens

---

### Step 4 — Set Blob Lifecycle Policy

```bash
az storage account management-policy create \
  --account-name $STORAGE_ACCOUNT \
  --resource-group $RESOURCE_GROUP \
  --policy @lifecycle-policy.json
```

**`lifecycle-policy.json`:**

```json
{
  "rules": [
    {
      "name": "move-to-cool",
      "enabled": true,
      "type": "Lifecycle",
      "definition": {
        "filters": { "blobTypes": ["blockBlob"], "prefixMatch": ["uploads/"] },
        "actions": {
          "baseBlob": {
            "tierToCool": { "daysAfterModificationGreaterThan": 30 }
          }
        }
      }
    },
    {
      "name": "move-to-archive",
      "enabled": true,
      "type": "Lifecycle",
      "definition": {
        "filters": { "blobTypes": ["blockBlob"], "prefixMatch": ["uploads/"] },
        "actions": {
          "baseBlob": {
            "tierToArchive": { "daysAfterModificationGreaterThan": 180 }
          }
        }
      }
    }
  ]
}
```

> **Why?** Automatically tier old documents to Cool after 30 days and Archive after 180 days to save storage costs.

### Step 5 — Create Cosmos DB Account

```bash
az cosmosdb create \
  --name $COSMOS_ACCOUNT \
  --resource-group $RESOURCE_GROUP \
  --locations regionName=$LOCATION failoverPriority=0 \
  --default-consistency-level Session \
  --kind GlobalDocumentDB
```

| Setting               | Reason                                         |
| --------------------- | ---------------------------------------------- |
| `Session` consistency | Balanced read consistency for user-scoped data |
| `GlobalDocumentDB`    | SQL (Core) API                                 |

---

### Step 6 — Create Cosmos DB Database

```bash
az cosmosdb sql database create \
  --account-name $COSMOS_ACCOUNT \
  --resource-group $RESOURCE_GROUP \
  --name $COSMOS_DATABASE
```

---

### Step 7 — Create Cosmos DB Container

```bash
az cosmosdb sql container create \
  --account-name $COSMOS_ACCOUNT \
  --resource-group $RESOURCE_GROUP \
  --database-name $COSMOS_DATABASE \
  --name $COSMOS_CONTAINER \
  --partition-key-path $PARTITION_KEY \
  --throughput 400
```

| Setting                  | Reason                                             |
| ------------------------ | -------------------------------------------------- |
| Partition key: `/userId` | Queries are scoped per user — optimal partitioning |
| Throughput: `400 RU/s`   | Minimum manual throughput for dev                  |

---

### Step 8 — Create App Service Plan + Web App

```bash
# Create App Service Plan
az appservice plan create \
  --name $APP_SERVICE_PLAN \
  --resource-group $RESOURCE_GROUP \
  --location $LOCATION \
  --sku B1 \
  --is-linux

# Create Web App for the .NET API
az webapp create \
  --name $APP_SERVICE_API \
  --resource-group $RESOURCE_GROUP \
  --plan $APP_SERVICE_PLAN \
  --runtime "DOTNETCORE:8.0"
```

## Day 2 — Security & Serverless

### Step 9 — Create Key Vault

```bash
az keyvault create \
  --name $KEY_VAULT \
  --resource-group $RESOURCE_GROUP \
  --location $LOCATION \
  --sku standard
```

### Step 10 — Store Secrets in Key Vault

```bash
# Store Cosmos DB connection string
COSMOS_CONN=$(az cosmosdb keys list --name $COSMOS_ACCOUNT \
  --resource-group $RESOURCE_GROUP --type connection-strings \
  --query "connectionStrings[0].connectionString" -o tsv)

az keyvault secret set --vault-name $KEY_VAULT \
  --name "CosmosDbConnectionString" --value "$COSMOS_CONN"

# Store Storage Account connection string
STORAGE_CONN=$(az storage account show-connection-string \
  --name $STORAGE_ACCOUNT --resource-group $RESOURCE_GROUP \
  --query connectionString -o tsv)

az keyvault secret set --vault-name $KEY_VAULT \
  --name "StorageConnectionString" --value "$STORAGE_CONN"
```

### Step 11 — Enable Managed Identity on App Service

```bash
az webapp identity assign \
  --name $APP_SERVICE_API \
  --resource-group $RESOURCE_GROUP

# Grant App Service access to Key Vault
API_PRINCIPAL_ID=$(az webapp identity show --name $APP_SERVICE_API \
  --resource-group $RESOURCE_GROUP --query principalId -o tsv)

az keyvault set-policy --name $KEY_VAULT \
  --object-id $API_PRINCIPAL_ID \
  --secret-permissions get list
```

### Step 12 — Create Function App

```bash
# Create Storage Account for Function App (required)
az storage account create \
  --name docvaultfuncstoragedev \
  --resource-group $RESOURCE_GROUP \
  --location $LOCATION \
  --sku Standard_LRS

# Create Function App
az functionapp create \
  --name $FUNCTION_APP \
  --resource-group $RESOURCE_GROUP \
  --storage-account docvaultfuncstoragedev \
  --consumption-plan-location $LOCATION \
  --runtime dotnet-isolated \
  --runtime-version 8 \
  --functions-version 4

# Enable Managed Identity on Function App
az functionapp identity assign \
  --name $FUNCTION_APP \
  --resource-group $RESOURCE_GROUP
```

## Day 3 — Events, Messaging & Observability

### Step 13 — Create Event Grid Topic

```bash
az eventgrid topic create \
  --name $EVENT_GRID_TOPIC \
  --resource-group $RESOURCE_GROUP \
  --location $LOCATION
```

### Step 14 — Create Service Bus Namespace + Queue

```bash
az servicebus namespace create \
  --name $SERVICE_BUS_NS \
  --resource-group $RESOURCE_GROUP \
  --location $LOCATION \
  --sku Basic

az servicebus queue create \
  --name $SERVICE_BUS_QUEUE \
  --namespace-name $SERVICE_BUS_NS \
  --resource-group $RESOURCE_GROUP
```

### Step 15 — Create API Management Instance

```bash
az apim create \
  --name $APIM_NAME \
  --resource-group $RESOURCE_GROUP \
  --location $LOCATION \
  --publisher-name "DocVault" \
  --publisher-email "admin@docvault.dev" \
  --sku-name Consumption
```

> **Note:** APIM provisioning takes 30-45 minutes for Consumption tier. Start this early.

### Step 16 — Create Application Insights

```bash
az monitor app-insights component create \
  --app $APP_INSIGHTS \
  --resource-group $RESOURCE_GROUP \
  --location $LOCATION \
  --application-type web

# Link to App Service
INSIGHTS_KEY=$(az monitor app-insights component show \
  --app $APP_INSIGHTS --resource-group $RESOURCE_GROUP \
  --query instrumentationKey -o tsv)

az webapp config appsettings set \
  --name $APP_SERVICE_API \
  --resource-group $RESOURCE_GROUP \
  --settings APPLICATIONINSIGHTS_CONNECTION_STRING="InstrumentationKey=$INSIGHTS_KEY"
```

## Day 4 — Containers (Stretch)

### Step 17 — Create Container Registry

```bash
az acr create \
  --name $ACR_NAME \
  --resource-group $RESOURCE_GROUP \
  --location $LOCATION \
  --sku Basic \
  --admin-enabled true
```

### Step 18 — Create Container Apps Environment + App

```bash
az containerapp env create \
  --name $CONTAINER_APP_ENV \
  --resource-group $RESOURCE_GROUP \
  --location $LOCATION

az containerapp create \
  --name docvault-api \
  --resource-group $RESOURCE_GROUP \
  --environment $CONTAINER_APP_ENV \
  --image "$ACR_NAME.azurecr.io/docvault-api:latest" \
  --target-port 8080 \
  --ingress external \
  --min-replicas 0 \
  --max-replicas 3
```
